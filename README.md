<img width="1920" height="966" alt="image" src="https://github.com/user-attachments/assets/f306eb90-9333-445b-a361-8621921d4a19" /># Website Toko Sembako Ibu

Website profil dan katalog produk sederhana untuk toko sembako lokal. Project ini dibangun menggunakan framework Laravel sebagai bagian dari pemenuhan tugas mata kuliah.

## Fitur Utama
- **Landing Page Publik**: Halaman informasi toko, profil singkat, katalog barang (tanpa transaksi online), peta lokasi (Google Maps), dan kontak WhatsApp.
- **Autentikasi Admin**: Sistem login/logout khusus untuk pengelola toko.
- **CRUD Manajemen Produk**: Fitur tambah, lihat, ubah, dan hapus data barang sembako yang dikelola secara eksklusif oleh admin.
- **Manajemen Sesi (Session)**: Pengamanan rute halaman admin dan pengelolaan sesi pengguna aktif.

## Teknologi yang Digunakan
- **Backend**: PHP, Laravel 13
- **Database**: MySQL (via Laragon)
- **Frontend / Styling**: Tailwind CSS (bawaan Laravel) / Blade Templates
